GovPilot — Innovation Procurement Platform

GovPilot is a digital platform designed to connect government departments with innovative startups through a transparent procurement workflow.

The platform enables departments to publish challenges, discover eligible startups, evaluate proposed solutions, conduct controlled pilots and track performance before procurement.

Key Features
Startup discovery
Eligibility verification
Expert evaluation
Pilot management
Performance tracking
Procurement workflow
Technical Approach
React Node.js PostgreSQL REST API Cloud Infrastructure

The proposed architecture uses a modular web-based platform with role-based access, structured workflows and centralized data management.
